# 🏠 RoomieSync — Smart Roommate Management

> Split expenses, assign chores, manage groceries, and keep the peace — all in one beautiful dashboard.

## 🌐 Live Pages

| Page | Description |
|------|-------------|
| `index.html` | Home / Landing page with hero, dashboard mockup, stats, feature highlights, testimonials |
| `features.html` | Full features grid with 10 feature cards, Free vs Pro comparison table |
| `howtojoin.html` | 3-step getting started guide, FAQ accordion, final CTA |

## 🎨 Design System

- **Font**: [Outfit](https://fonts.google.com/specimen/Outfit) (Google Fonts)
- **Primary Color**: `#6C63FF` (Purple)
- **Accent Color**: `#00d4aa` (Teal-Green)
- **Dark Background**: `#1a1a2e`
- **Glass Effects**: Backdrop blur, semi-transparent backgrounds
- **Animations**: Scroll-triggered reveals, floating particles, counter animations

## 🚀 Getting Started

1. Clone the repo:
   ```bash
   git clone https://github.com/harsh27d/Roomproject.git
   ```
2. Open `index.html` in your browser — no build step needed!

## ✨ Features

- 💸 **Smart Expense Splitting** — equal or custom shares with auto-reminders
- 📋 **Chore Rotation** — fair, automatic task assignment
- 🛒 **Shared Grocery List** — real-time collaborative shopping
- 🔔 **Smart Notifications** — gentle nudges for bills and deadlines
- 📊 **Spending Insights** — beautiful charts and monthly summaries
- 🔒 **Privacy First** — encrypted, no ads, no data selling
- 📱 **Fully Responsive** — works on all devices
- ⚡ **Real-Time Sync** — instant updates across all devices
